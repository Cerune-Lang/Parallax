# Contributing / コントリビューション

- Add deterministic `.ceru` fixtures and matching `.expected` standard-output files.
- Document the Cerune commit and environment if behavior changes.
- Tests must be safe to run in a sandbox without secrets, network targets, or external services.
- Discuss changes to the comparison oracle and supported backends before significantly broadening scope.
- Do not publish unpatched security findings: see [SECURITY.md](SECURITY.md).
