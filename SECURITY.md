# Security Policy / セキュリティポリシー

Parallax is an experimental testing project. Test success does not imply security assurance.

Do not disclose unpatched vulnerabilities or working exploit details in public issues/PRs.
未修正の脆弱性や悪用可能な内容は公開 Issue / PR に投稿しないでください。

Report potential Cerune compiler/runtime vulnerabilities privately via [Cerune's vulnerability reporting](https://github.com/Cerune-Lang/Cerune/security/advisories/new) where enabled, or another approved private maintainer channel. Include affected revision, platform, minimum reproducer, and expected vs. actual result.

Publish regression cases only after appropriate mitigation or coordinated disclosure.
